# 自动体检

在设置页的「自动体检」中启用启动检查，或选择每 30 分钟、1 小时、6 小时检查。选项随其他设置一起保存，默认均关闭。本地模式使用设置中的 Storage 路径，远程模式使用 Registry 地址并需要 cached-list 插件。

自动体检仅在应用运行时执行，仅检查、不修复；未配置目标时静默跳过。所有检查与手动修复共用执行锁，忙碌时跳过本次自动检查，等待下个周期。结果保留在当前应用会话的 zustand store，体检页可显示最近结果、目标和检查时间。侧边栏显示有问题的包数；失败、元数据无法解析或插件过旧时显示警告，悬停可查看原因。手动修复后会重新检查并更新提示。
